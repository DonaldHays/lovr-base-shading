# Changelog

## dev

### Added

- Surface shaders can now be compiled with flags. The flags `baseFog` and
  `baseShadow` have been added.

### Changed

- Updated for LÖVR v0.19.0. Uses of `Vec3` have been replaced with `vector`, and
  uses of `Vec4` have been replaced with new `BaseColor` and `BaseV4` types.

## v0.0.0 - 2025-03-11

### Added

- Initial release!
